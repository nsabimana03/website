How it works

  1. Create a student profile: Enter your qualifications and preferences (frontend-only, not stored securely).
  2. Search & filter: Use search and filters to find matches from the demonstration dataset.
  3. Match & review: The system ranks matches and explains which criteria are met or need verification.
  4. Follow official links: Use the official source/application links on each card. External links open in a new tab.
